# Exemples SQL — Guide MySQL et MariaDB

Ce dépôt rassemble les exemples SQL associés au *Guide complet des types de données, attributs et contraintes pour MySQL et MariaDB*.

## Organisation

- `00-demarrage/` : connexion, versions et configuration initiale
- `01-la-donnee/` : notions générales sur les données
- `02-performances/` : performances et bonnes pratiques
- `03-numerique/` : types numériques
- `04-chaines-caracteres/` : chaînes de caractères
- `05-date-heure/` : dates et heures
- `06-donnees-binaires/` : données binaires et sécurité
- `07-spatial/` : types spatiaux
- `08-intelligence-artificielle/` : vecteurs et exemples liés à l'IA
- `09-attributs-colonnes/` : attributs de colonnes
- `10-contraintes-index/` : contraintes et index
- `11-application-ecommerce/` : exemple d'application complète
- `tests/` : essais séparés pour MySQL et MariaDB
- `docs/` : correspondance avec les chapitres et notes de compatibilité

## Utilisation

1. Consultez le README du dossier concerné.
2. Vérifiez la version de MySQL ou MariaDB utilisée.
3. Exécutez les scripts uniquement dans une base de test, sauf si vous avez vérifié leurs effets.
4. Certains scripts peuvent créer ou supprimer des objets de base de données : lisez-les avant exécution.

Les scripts sont à compléter et à tester avant publication. Les compatibilités peuvent varier selon les versions du serveur.
