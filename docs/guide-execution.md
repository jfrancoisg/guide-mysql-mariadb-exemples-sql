# Guide d'exécution

- Utilisez une base de test.
- Lisez chaque script avant de l'exécuter.
- Vérifiez la version du serveur et les privilèges nécessaires.
- Exécutez les scripts de création avant les scripts de données, puis les requêtes de démonstration.
- Les scripts de suppression doivent être clairement identifiés et utilisés avec prudence.
- Documentez les résultats réellement observés.
