# Contribuer

Merci de contribuer à l'amélioration des exemples.

Avant de proposer une modification :
- indiquez le chapitre ou le sujet concerné ;
- précisez les versions de MySQL et/ou MariaDB testées ;
- fournissez le résultat attendu si cela aide à vérifier l'exemple ;
- n'ajoutez aucune donnée personnelle, aucun mot de passe ni aucune clé secrète.

N'exécutez pas les scripts sur une base de production sans revue préalable.
